# Cybersecurity and Ethical Hacking Internship

This repository contains my work completed during the ApexPlanet Cybersecurity and Ethical Hacking Internship.

The internship involved practical cybersecurity activities, ethical hacking, vulnerability analysis, security awareness, and incident response in controlled lab environments.

## Internship Tasks

### Task 1 – Cybersecurity Fundamentals
Basic cybersecurity concepts and practical activities completed as part of the internship.

### Task 2 – Cybersecurity Practical Activities
Hands-on cybersecurity exercises and documentation.

### Task 3 – Security Testing and Analysis
Practical security testing activities with screenshots and supporting documentation.

### Task 4 – Exploitation & System Security
- Penetration testing methodology
- Network and service scanning using Nmap
- Controlled exploitation using Metasploit
- Password attack demonstration
- Phishing awareness simulation
- Malware analysis basics
- System hardening

### Task 5 – Phishing Detection & Incident Response
- Python-based phishing detection tool
- Suspicious URL analysis
- Phishing indicator detection
- Multiple test cases
- Incident response simulation
- Security awareness
